HILT¶

HILT (Hardware-In-the-Loop Testing) is Python HIL testing with a pit of success: composable tests, guardrails that make a bad test hard to write, and an engine that won't let an unhandled failure pass silently. A Floor Technician categorizes a failure and starts the right recovery protocol without reading suite source; a developer writes the suite that makes that possible.

  • Floor technicians: the station page is the Floor Technician guide. That is the URL that belongs on a station label.
  • Suite authors: start with getting started, then the overview, idioms, and contracts.
  • Public surface: API stability is the policy; the API reference is generated from the public names' docstrings.
  • Inspector contributors: the target specification carries the terminal workflow that hilt inspect opens.

Build this site locally with make docs. A broken cross-reference fails the gate. Nothing hosts it: GitLab renders every page from docs/ on main, and a release branch carries the built site under docs/site/ (make docs-release) so a station can open it from a clone without a network (#138).
